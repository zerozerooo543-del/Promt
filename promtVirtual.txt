Saya ingin kamu membuat source code aplikasi Android lengkap dan WORK 
untuk Dual Space / Clone App yang HANYA berfungsi untuk 1 aplikasi saja, 
yaitu Mobile Legends: Bang Bang (MLBB).

SPESIFIKASI APLIKASI:

1. NAMA APLIKASI: "ML Dual Space" (atau nama lain yang kamu sarankan)
2. PACKAGE NAME: com.mldual.space
3. MIN SDK: 24 (Android 7.0)
4. TARGET SDK: 34 (Android 14)
5. BAHASA: Kotlin (utama) + Java untuk native hook
6. UI: Material Design 3, tema dark mode gaming

FITUR UTAMA YANG HARUS ADA:

A. Virtual Engine / Sandbox
   - Menggunakan VirtualApp (VA) atau VirtualXposed atau 
     pendekatan Multi-User / Work Profile
   - Bisa menginstall dan menjalankan 2 instance MLBB secara paralel
   - Support Android 7 sampai Android 14 (jelaskan limitasi tiap versi)
   - Support arsitektur ARM64 (wajib) dan ARMv7 (opsional)

B. Manajemen Kloning
   - Tombol "Add MLBB" untuk clone aplikasi
   - Deteksi otomatis jika MLBB sudah terinstall di device
   - Bisa buat maksimal 3 clone (main + 2 clone)
   - Ikon clone dengan badge angka (1, 2, 3)
   - Uninstall / delete clone tanpa menghapus MLBB asli

C. Isolasi Data
   - Data OBB, cache, dan shared_prefs terpisah per clone
   - Virtual IMEI, Android ID, MAC Address, dan Device ID 
     untuk menghindari deteksi "same device" dari Moonton
   - Virtual storage path: /data/data/com.mldual.space/virtual/[clone_id]/

D. Kinerja & Kompatibilitas
   - Support GPU rendering (OpenGL ES 3.0 & Vulkan)
   - Tidak lag saat 2 instance MLBB berjalan bersamaan
   - Support game mode (matikan notifikasi, boost CPU)

E. Keamanan (PENTING)
   - Jangan sertakan fitur cheat / hack / maphack
   - Aplikasi hanya untuk menjalankan 2 akun MLBB di 1 HP
   - Sertakan disclaimer bahwa penggunaan bisa melanggar ToS Moonton

F. Permission yang dibutuhkan
   - QUERY_ALL_PACKAGES
   - MANAGE_EXTERNAL_STORAGE (opsional)
   - FOREGROUND_SERVICE
   - REQUEST_INSTALL_PACKAGES
